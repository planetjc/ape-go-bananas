Three steps.
You sign off on each.

1

Extract

Every fact in the slides and transcript, each with the line it came from. You read the inventory first.

2

Organize

A plan of which facts become which cards, held to the lecture objectives. Nothing is written until you approve it.

3

Cards

Cloze cards written to the plan. Flag what reads wrong; an independent auditor and adjudicator rule on each flag.

Then straight into Anki, or out as an .apkg to import by hand.

See how it works

One lecture, start to finish, in the real app. Sped up: each step takes minutes, and it waits for you at every review.

Manage classes, one semester at a time.

Switch to School and set up a semester and the classes in it. Give a class the syllabus, notes or study guide, and the agent turns them into a short brief every deck in the class reads. You read it first.

  • The brief brings the exam dates and what is off the exam. Where it and the lecture objectives differ, the lecture wins.
  • Each deck is sized to fit a daily new-card limit before the exam.
  • Coming up lists every exam in the term, across all classes.
  • Only want cards? Stay in Decks, and none of this shows.

Keep everything local.

Only what goes to the agent leaves the computer. No accounts, no server, no telemetry. Course folders stay where they are, API keys go to the OS keychain, and updates install only with a click.

First launch

Free software, not notarized, so each system asks once.
macOSThe first open says it “cannot be opened”. System Settings → Privacy & Security → Open Anyway.
WindowsSmartScreen says the publisher is unknown. More info → Run anyway.
LinuxMark the AppImage executable (chmod +x) or install the .deb.
Already have a deck.json? The browser tool runs the same engine in a tab: check a deck, read every card, export a real .apkg. Nothing to install, nothing uploaded.
